What is a second brain?

Your AI agents forget. Every session starts blank, and every tool keeps its own private memory.

A second brain is the one place you keep what makes them work your way, as plain files you own.

Memory

Your preferences, corrections and lessons learned: how you like commits written, which mistakes to avoid, what a project already decided.

Skills

Reusable playbooks for tasks you repeat, so you explain them once instead of every session.

Ways of working

Per-repo instructions, permissions and hooks: the rules that turn a generic agent into your teammate.

Why you may need one

New machine

A laptop dies or gets replaced. Without a backup, months of tuning are gone.

Tool switch or outage

Move between Claude, Codex, Gemini or Cursor without starting from zero. One flattened file works everywhere.

Access changes

Accounts, plans and policies change. Your knowledge shouldn't depend on one vendor's settings page.

It compounds

Each correction you save makes every future session better. A brain you back up keeps its value.

Share what is generic

Publish the method and examples, keep the private parts private, with guardrails that enforce the line.

Second brain vs RAG

They solve different problems and work well together. RAG helps an agent look things up in a large body of knowledge. A second brain tells an agent how to behave and what you have already decided.

Use both. Keep your conventions and decisions in the second brain, and point it at a RAG tool for large reference material. The second brain can even say when and how to use that tool.

The loop

Preview & gather

Run scripts/gather.sh --dry-run first to preview every file and flag emails, IPs and home paths. Then run it for real: pick private to copy everything, or public to keep only clean skills.

Trim

Read the diff. Delete memory about organizations, clients and other people. Keep working-style notes and lessons learned.

Check

scripts/check-denylist.sh and gitleaks detect must pass. Put private terms in the EXTRA_DENYLIST secret.

Flatten

python3 scripts/build-portable-context.py produces the single file other agents can read.

Commit privately

Push to a private repo and gather again whenever your memory has grown. To publish a template, feed a separate public repo from an explicit allowlist, never the reverse.

Or let an agent do it: the second-brain-gather skill walks through this loop and flags anything risky.

Get started

Copy the template into a private repo of your own, then make it yours.

# 1. copy the template into your own private repo
$ git clone https://github.com/mariotristan/tristan-second-brain-public my-second-brain
$ cd my-second-brain

# 2. preview, then gather your skills, memory and settings
$ scripts/gather.sh --dry-run
$ scripts/gather.sh

# 3. flatten memory for any agent
$ python3 scripts/build-portable-context.py

# 4. keep it clean
$ pre-commit install
Download as .zip No GitHub account needed.

Built-in guardrails

A backup repo drifts toward leaking. These checks run on every push.

Secret scanning

gitleaks in CI and as a pre-commit hook.

Denylist check

Fails on emails, home paths, IP addresses and key folders.

Private terms

Add your own forbidden words through a repository secret, so they never appear in the repo.
