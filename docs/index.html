Get started

Copy the template into a private repo of your own, then make it yours.

# 1. copy the template into your own private repo
$ git clone https://github.com/mariotristan/tristan-second-brain-public my-second-brain
$ cd my-second-brain

# 2. add your skills, memory and settings under claude/

# 3. flatten memory for any agent
$ python3 scripts/build-portable-context.py

# 4. keep it clean
$ pre-commit install
